1. GLOBAL ARCHITECTURE & API CONVENTIONS
================================================================================
- Frontend Base URL Configuration (.env):
    VITE_API_BASE_URL=http://localhost:8000/api/v1  (or production API server)
- Transport & Format: HTTPS (TLS 1.3), Content-Type: application/json
- Authentication:
    Authorization: Bearer <jwt_access_token>
- Standard Success Envelope (HTTP 200 / 201):
    {
      "success": true,
      "data": { ... } | [ ... ],
      "message": "Human-readable action status confirmation"
    }
- Standard Error Envelope (HTTP 4xx / 5xx):
    {
      "success": false,
      "error": "Detailed error reason string"
    }
- Role Requirement: All endpoints below strictly require the authenticated user 
  to possess role: 'super_admin' (HTTP 403 Forbidden if called by 'admin' or 'employee').

3.4. UPDATE / CALIBRATE OFFICE GEOFENCE & SHIFT POLICY
--------------------------------------------------------------------------------
- Method: PUT
- Path: /api/v1/offices/:id/calibration
- Path Parameter: id (UUID of the office)
- Headers: Authorization: Bearer <super_admin_token>
- Description: Calibrates GPS geofence circle and shift hours enforced by mobile app.
- Request Body (JSON):
    {
      "office_name": "Tripura Jal Board - Agartala Headquarters",
      "address": "Sakuntala Rd, Sadar, Agartala, Tripura 799001",
      "latitude": 23.831500,
      "longitude": 91.286800,
      "radius_meters": 100,
      "shift_start_time": "10:00 AM",
      "shift_end_time": "05:30 PM",
      "standard_break_allowance_minutes": 60,
      "break_grace_period_minutes": 15
    }
- Business Logic:
    - Mobile app computes Euclidean/Haversine distance from this (latitude, longitude).
    - If distance > radius_meters, mobile app blocks biometric check-in.
    - Excess Break Alert is calculated as: standard_break_allowance_minutes + break_grace_period_minutes (e.g. 60 + 15 = 75 min).
- Success Response (HTTP 200 OK):
    {
      "success": true,
      "message": "Office geofence calibration updated successfully."
    }

6. GLOBAL ATTENDANCE SESSIONS & SUPER ADMIN OVERRIDES
================================================================================

--------------------------------------------------------------------------------
6.1. QUERY ALL ATTENDANCE SESSIONS (GLOBAL)
--------------------------------------------------------------------------------
- Method: GET
- Path: /api/v1/attendance/sessions
- Query Parameters:
    - office_id: (optional, string: 'all' or specific office UUID)
    - date: (optional, YYYY-MM-DD, default: today)
    - status: (optional, 'working' | 'on_break' | 'on_official_work' | 'checked_out')
    - search: (optional, string, searches employee name / code)
- Success Response (HTTP 200 OK): Array of session records with nested employee objects.

--------------------------------------------------------------------------------
6.2. FORCE OVERRIDE ATTENDANCE SESSION (SUPER ADMIN ONLY)
--------------------------------------------------------------------------------
- Method: PUT
- Path: /api/v1/attendance/sessions/:id/override
- Path Parameter: id (UUID of attendance session)
- Headers: Authorization: Bearer <super_admin_token>
- Description: Allows Super Admin to directly adjust session timestamps, status, 
  break minutes, or confirmed working minutes with mandatory audit remark.
- Request Body (JSON):
    {
      "check_in_time": "2026-11-23T10:00:00+05:30",                // (string, ISO timestamp)
      "check_out_time": "2026-11-23T17:30:00+05:30",               // (string | null, ISO timestamp)
      "active_status": "checked_out",                               // ('working' | 'on_break' | 'on_official_work' | 'checked_out')
      "confirmed_working_minutes": 420,                             // (integer)
      "actual_break_minutes": 30,                                  // (integer)
      "admin_remarks": "Adjusted check-in timestamp per verified executive order." // (string, MANDATORY)
    }
- Business Rules:
    - The backend MUST write an entry into the audit_logs table recording the 
      super admin's user ID, old values, new values, and admin_remarks.
- Success Response (HTTP 200 OK):
    {
      "success": true,
      "message": "Attendance session overridden and audit remark recorded."
    }

10. COMPLETE POSTGRESQL / SUPABASE DATABASE SCHEMA & SEED SCRIPT
================================================================================
Run the following SQL script to set up all tables and seed the initial Super Admin:

```sql
-- 1. PROFILES TABLE (Supabase auth.users extension or standalone profiles)
CREATE TABLE IF NOT EXISTS profiles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  full_name VARCHAR(255) NOT NULL,
  role VARCHAR(50) NOT NULL CHECK (role IN ('super_admin', 'admin', 'employee')),
  status VARCHAR(50) DEFAULT 'active' CHECK (status IN ('active', 'suspended', 'inactive')),
  assigned_office_ids TEXT[] DEFAULT '{}',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. OFFICES TABLE
CREATE TABLE IF NOT EXISTS offices (
  id VARCHAR(100) PRIMARY KEY,
  office_name VARCHAR(255) NOT NULL,
  address TEXT NOT NULL,
  latitude DOUBLE PRECISION NOT NULL,
  longitude DOUBLE PRECISION NOT NULL,
  radius_meters INT NOT NULL DEFAULT 100,
  time_zone VARCHAR(100) DEFAULT 'Asia/Kolkata',
  working_days INT[] DEFAULT '{1,2,3,4,5,6}',
  standard_break_allowance_minutes INT DEFAULT 60,
  break_grace_period_minutes INT DEFAULT 15,
  shift_start_time VARCHAR(20) DEFAULT '10:00 AM',
  shift_end_time VARCHAR(20) DEFAULT '05:30 PM',
  status VARCHAR(50) DEFAULT 'active',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. ANNUAL HOLIDAYS TABLE
CREATE TABLE IF NOT EXISTS holidays (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  holiday_name VARCHAR(255) NOT NULL,
  holiday_date DATE NOT NULL,
  end_date DATE,
  year INT NOT NULL,
  holiday_type VARCHAR(50) DEFAULT 'gazetted' CHECK (holiday_type IN ('gazetted', 'state_declared', 'restricted', 'local_festival')),
  office_id VARCHAR(100) REFERENCES offices(id) ON DELETE SET NULL,
  description TEXT,
  created_by UUID REFERENCES profiles(id) ON DELETE SET NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 4. EMPLOYEES TABLE (Enrolled by Admins only)
CREATE TABLE IF NOT EXISTS employees (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  employee_code VARCHAR(100) UNIQUE NOT NULL,
  full_name VARCHAR(255) NOT NULL,
  designation VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  mobile_number VARCHAR(50) NOT NULL,
  office_id VARCHAR(100) REFERENCES offices(id),
  date_of_birth DATE,
  residential_address TEXT,
  status VARCHAR(50) DEFAULT 'active' CHECK (status IN ('active', 'suspended')),
  created_by UUID REFERENCES profiles(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 5. ATTENDANCE SESSIONS TABLE
CREATE TABLE IF NOT EXISTS attendance_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  employee_id UUID REFERENCES employees(id) ON DELETE CASCADE,
  office_id VARCHAR(100) REFERENCES offices(id),
  attendance_date DATE NOT NULL,
  check_in_time TIMESTAMP WITH TIME ZONE NOT NULL,
  check_out_time TIMESTAMP WITH TIME ZONE,
  active_status VARCHAR(50) DEFAULT 'working',
  office_working_minutes INT DEFAULT 0,
  actual_break_minutes INT DEFAULT 0,
  approved_official_work_minutes INT DEFAULT 0,
  confirmed_working_minutes INT DEFAULT 0,
  check_in_latitude DOUBLE PRECISION,
  check_in_longitude DOUBLE PRECISION,
  check_in_distance_meters DOUBLE PRECISION,
  check_out_latitude DOUBLE PRECISION,
  check_out_longitude DOUBLE PRECISION,
  check_out_distance_meters DOUBLE PRECISION,
  is_finalized BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 6. SYSTEM AUDIT LOGS TABLE
CREATE TABLE IF NOT EXISTS audit_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id) ON DELETE SET NULL,
  user_name VARCHAR(255),
  user_email VARCHAR(255),
  action VARCHAR(100) NOT NULL,
  entity VARCHAR(100) NOT NULL,
  entity_id VARCHAR(100),
  payload JSONB,
  ip_address VARCHAR(50),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
